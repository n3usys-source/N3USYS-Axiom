# Changelog

All notable AXIOM changes are documented here.

## 0.2.2 — Functional Aurorae Integration

- Added N3USYS AXIOM Aurorae window decoration.
- Added dark structural window borders with cyan accents.
- Added centered cyan window titles.
- Corrected Aurorae package naming and rc filename.
- Added functional minimize, maximize/restore, and close control regions.
- Accepted minimal/invisible control glyphs as the current visual state.

## 0.2.1 — Integrated Theme Package

- Consolidated AXIOM Plasma, color, Konsole, and wallpaper components.
- Established the AXIOM dark/cyan design language.

## 0.2.0 — Initial Plasma Implementation

- Initial KDE Plasma desktop theme implementation.
