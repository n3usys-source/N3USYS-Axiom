# N3USYS AXIOM Design System

## Purpose

AXIOM translates the N3USYS visual language into a usable KDE Plasma desktop environment.

## Core Palette

- **Signal Cyan:** `#00D9FF`
- **Deep Surface:** near-black / deep blue-black
- **Primary Text:** light cyan-white
- **Secondary Text:** muted cyan/gray
- **Structural Lines:** subdued blue-gray

## Visual Principles

### 1. Structure Before Decoration

Borders, frames, spacing, and alignment communicate system structure before decorative effects are introduced.

### 2. Signal Color

Cyan represents active signal, focus, state, and interaction.

### 3. Dark Field

The near-black background reduces visual noise and provides contrast for the cyan signal layer.

### 4. Minimalism

AXIOM favors deliberate restraint over excessive ornamentation. Every visual element should communicate hierarchy, state, or function.

### 5. Instrument Aesthetic

The system draws from instrumentation, HUDs, technical consoles, and computational interfaces rather than conventional desktop decoration.

## Typography

Use clean sans-serif typography with strong hierarchy. Titles and labels may use increased letter spacing for an instrument-panel effect.

## Window Decoration

The Aurorae implementation uses:

- thin cyan structural borders
- dark window surfaces
- centered cyan titles
- minimal control treatment
- functional control hit regions

## Future Direction

AXIOM may evolve into a complete KDE Global Theme with coordinated Plasma, Aurorae, icons, colors, cursors, wallpapers, and application styling.
